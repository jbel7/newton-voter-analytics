# Newton Voter Analytics

Voter Data Analysis Platform for Newton, Massachusetts

[![Live Demo](https://img.shields.io/badge/Live-Demo-success?style=for-the-badge)](https://cs-webapps.bu.edu/belsanyj/voter_analytics/)

**Live Application**: [https://cs-webapps.bu.edu/belsanyj/voter_analytics/](https://cs-webapps.bu.edu/belsanyj/voter_analytics/)

---

## About

Newton Voter Analytics is a web application for exploring and analyzing voter registration data from Newton, Massachusetts. The platform provides filtering capabilities and data visualizations for the city's voter records.

**Dataset Size**: 58,759 registered voters

---

## Features

### Voter List
- Browse all registered voters in Newton, MA
- Pagination system (100 voters per page, 588 total pages)
- Individual voter detail pages
- Privacy-protected display (names are masked in list view)

### Voter Information Displayed
- First and last name (masked in list view)
- Street address
- Date of birth
- Party affiliation
- Voter score (0-5)
- Link to detailed voter profile

### Advanced Filtering System

**Party Affiliation Filter**  
Filter by political party including: D (Democrat), R (Republican), U (Unenrolled), and various other party designations (A, AA, CC, E, EE, FF, G, GG, H, HH, J, K, L, O, P, Q, S, T, V, W, X, Y, Z)

**Birth Year Range**  
- Minimum birth year: 1913-2005
- Maximum birth year: 1913-2005
- Filter voters by age range

**Voter Score**  
Filter by participation score ranging from 0 to 5

**Election History**  
Filter by participation in specific elections:
- 2020 State Election
- 2021 Town Election
- 2021 Primary
- 2022 General Election
- 2023 Town Election

**Filter Controls**
- Apply Filters button
- Reset Filters option
- Multiple filters can be combined

### Data Visualization
- Graphs page available for data analysis
- Accessible through navigation menu

---

## Navigation

The application includes:
- **Voter List**: Main page with searchable/filterable voter database
- **Graphs**: Data visualization and analytics

---

## Data Privacy

The application displays publicly available voter registration information. Names are masked in the list view for privacy (displayed as asterisks with partial letters visible).

---



## Usage

1. Visit the voter list page to browse all registered voters
2. Use filters to narrow down results by:
   - Party affiliation
   - Age (birth year range)
   - Voter participation score
   - Specific election participation
3. Click on individual voters to view detailed profiles
4. Navigate to the Graphs page for data visualizations
5. Reset filters to return to full dataset

---

## Data Source

Voter registration data is from Newton, Massachusetts public records.
